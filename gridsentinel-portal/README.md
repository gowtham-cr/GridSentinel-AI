# GridSentinel Portal

Create a cinematic 3D galaxy opening screen for GridSentinel AI.

Use a deep-space galaxy with animated stars, moving nebula,

a glowing cosmic portal and rotating holographic rings.

Create smooth camera movement and particle animations.

Display:

GRIDSENTINEL AI

WELCOME TO THE GRID

WELCOME, GOWTHAM

Add an animated INITIALIZE SYSTEM button.

On clicking it, create a smooth cinematic transition

through the portal into the cybersecurity dashboard.

Use React Three Fiber, Three.js, GSAP and Framer Motion.

Make it premium, immersive, responsive and optimized

for smooth performance.

Keep the opening screen separate from the dashboard

so both can be developed independently.
